About QuickNotes

QuickNotes helps you quickly capture ideas and keep useful notes organized. Use it to save thoughts before they disappear and find them again when you need them.

How to use QuickNotes

  1. Enter your idea in the new note field.
  2. Select Add Note to save it to your list.
  3. Review your notes whenever you need a reminder.

Features

  • Quickly add ideas to a simple notes list.
  • See your saved notes together in one place.
  • Use keyboard shortcuts to work more efficiently.

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
