About QuickNotes

QuickNotes is a simple web application that allows users to quickly capture and manage their notes. It is designed to be user-friendly and efficient, enabling users to jot down ideas before they forget them.

How to use QuickNotes

  • Click the "Add Note" button to create a new note.
  • Edit the note by clicking on it.
  • Delete a note by clicking the "Delete" button.

KeyBoard Shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the note
